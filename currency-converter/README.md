# Currency Converter

## Description
A simple Python currency converter that uses an API to retrieve exchange rates and converts an amount from one currency to another.

## Features
- Convert between different currencies
- Get exchange rates using an API
- User input for source and target currencies
- Supports decimal amounts
- Handles API errors
- Displays the converted result

## How to Run
```bash
python main.py
```
